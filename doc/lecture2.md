## 受信機が出力するデータをみてみよう

| 種別    | 内容                                                         |
|---------|--------------------------------------------------------------|
| GPGGA   | 測位時刻・緯度経度・高度などの基本測位情報                   |
| GNGLL   | 緯度・経度と UTC時刻                                         |
| GNGSA   | 使用中の衛星 ID・DOP                                         |
| GPGSV   | 観測できている衛星の一覧と各衛星の詳細（仰角、方位、SNR）     |
| GNGNS   | 緯度・経度・Fix種別（GPS/GLONASSなど）・衛星数など           |
| GNGMC   | 速度・方位角・日付・緯度経度など                             |
| GNVTG   | 地上速度と進行方位                                           |
| GNZDA   | 時刻情報                                                     |
| L1BAT   | バッテリー電圧                                               |
| L1MAG   | 磁気センサの出力                                             |
